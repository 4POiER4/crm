# VIP TOURS CRM

Локальная CRM туристического агентства с клиентами, заявками, подборками туров, бронированиями, оплатами, документами, задачами и отчётами.

Базовая валюта — белорусский рубль (BYN). Доллары США и евро поддерживаются с сохранением курса к BYN.

## Запуск через Docker

Требуются Docker Desktop и Docker Compose.

```powershell
docker compose up --build -d
```

После запуска откройте [http://localhost:8787](http://localhost:8787).

Контейнер использует локальный административный вход. Данные базы и прикреплённые документы сохраняются в именованном томе `vip-tours-crm-data` и остаются после перезапуска или пересборки контейнера.

Проверить состояние:

```powershell
docker compose ps
docker compose logs -f crm
```

Остановить приложение без удаления данных:

```powershell
docker compose down
```

Удаление тома `vip-tours-crm-data` удалит всю локальную базу и документы.
